# 🏢 智慧建築評估計分工具

> 台灣智慧建築標章評估的一站式互動計分工具，支援 **2016 版**與 **2024 版**雙版本。

🔗 **線上使用**：[https://steven4dev.github.io/smart-building-label-scoring/](https://steven4dev.github.io/smart-building-label-scoring/)

---

## 功能特色

- **雙版本切換**：2016 版（辦公服務類 / 住宿類 / 商業類）與 2024 版一鍵切換
- **即時計分**：勾選評估項目後立即顯示總分、各指標分佈、達標等級
- **等級儀表板**：圓形進度圖 + 各指標橫條 + 門檻標示（合格 / 銅 / 銀 / 金 / 鑽石）
- **Checkbox 累計取分**：多數評估項目以水平 pill 標籤呈現，逐項勾選後自動加總，並顯示目前分數與下一門檻提示
  - **累加型**（每項 +N 分，有上限）：如備援機制、空調智慧化節能等
  - **門檻型**（勾選 N 項得 X 分）：如區塊鏈加密機制（2項+2分/3項+4分）、災害告警顯示、水平佈線系統等
- **快捷工具列**
  - 💡 AI 建議取分：一鍵套用專家建議的合理取分組合，**不改動展開/收折狀態**
  - ☑ 全勾選（不含加分）：僅勾選基本項目，**不改動展開/收折狀態**
  - ☑ 全勾選（全加分）：含所有加分項目，**不改動展開/收折狀態**
  - 🔄 清除全部：重置所有勾選，**不改動展開/收折狀態**
- **取分儀表收折**：點擊 ▲ 收折取分儀表 / ▼ 展開取分儀表，縮小頂部空間以便瀏覽細項
- **亮 / 暗主題**：自動跟隨系統設定，可手動切換（🌞 / 🌙）

## 版本差異

| | 2016 版 | 2024 版 |
|---|---|---|
| 建築類別 | 辦公服務類 / 住宿類 / 商業類 | 統一（不分類） |
| 滿分 | 200 分 | 240 分（含加分） |
| 指標數 | 8 項 | 6 項 |
| 等級門檻 | 銅 50 / 銀 90 / 金 120 / 鑽 140 | 銅 70 / 銀 100 / 金 130 / 鑽 150 |

## 使用方式

直接開啟上方連結，無需安裝。

1. 頂部切換 **2016版 / 2024版**
2. 依建築實際情況**勾選**各評估子項（pill 標籤可多選，自動累計）
3. 頂部儀表板即時顯示**總分**與**預計達標等級**
4. 可使用工具列快捷按鈕輔助作業
